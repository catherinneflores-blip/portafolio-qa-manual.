
# Portafolio de QA Manual — SauceDemo

## Perfil profesional

Portafolio práctico de pruebas de control de calidad de software (QA), enfocado en pruebas funcionales manuales, documentación de casos de prueba, validación de resultados y registro de incidencias.

## Proyecto: SauceDemo

**Objetivo:** demostrar el proceso de planificación, ejecución y documentación de pruebas manuales en una aplicación web de comercio electrónico de demostración.

### Alcance de las pruebas

- Inicio de sesión correcto e incorrecto.
- Validación de mensajes de error y campos obligatorios.
- Visualización y ordenamiento de productos.
- Agregar y eliminar productos del carrito.
- Validación del formulario de compra.
- Revisión de subtotal, impuestos y total.
- Finalización de la compra y navegación posterior.

## Resultados documentados

- **20 casos de prueba manuales ejecutados y documentados.**
- **1 incidencia pendiente de reproducir**, relacionada con un mensaje de sesión durante el proceso de compra.
- **11 verificaciones de regresión documentadas**; no todas se han ejecutado en una ronda independiente.
- Evidencias de ejecución mediante capturas de pantalla.
- Procedimiento de QA y resumen del proyecto.

## Entregables

- Archivo Excel con la planificación, los casos de prueba, las incidencias, las verificaciones de regresión y el resumen.
- PDF con evidencias de ejecución.
- PDF de presentación del portafolio.
- Capturas de pantalla de la aplicación durante las pruebas.

## Herramientas utilizadas

- SauceDemo.
- Navegador web.
- Excel compatible / Google Sheets.
- Capturas de pantalla.
- GitHub.

## Transparencia

Este es un proyecto práctico de portafolio realizado sobre una aplicación de demostración. Los resultados corresponden a las pruebas ejecutadas y observadas. La incidencia registrada queda pendiente de reproducirse para determinar si es un problema persistente.
